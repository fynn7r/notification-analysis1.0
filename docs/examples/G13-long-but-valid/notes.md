# G13：长文但未超限，关键信息在最末尾

**测什么**：4.8 万字的参赛指南，**截止时间写在全文最后一句**，静置在一堆重复条款之后。

**期望**：正常走完整条管线，`deadline` 为 `2026-11-15T17:00:00+08:00`，不因为长而被拒。

**为什么值得测**：这条和 G10 是一对。G10 守「超了要拒」，G13 守「没超要放行」。只测拒绝，会让人误以为上限越小越安全；只测放行，又看不出护栏到底立在哪。

更实际的用途是**注意力**。把真正的信息放在 4.8 万字之后，是最容易漏掉的位置——真实场景里，一份长指南的报名截止往往就写在最后那句「逾期不再受理」里。离线回放测的是「契约放行 + 字符处理不出错」，`--live` 抽检才算真正检验模型有没有在长文里读到文末。

**通过判据**：离线模式下不报错、字段与断言一致；`--live` 模式下仍能取到文末的截止时间。

**注意**：这条样本故意用了大量重复条款撑长度，不是为了模拟真实文体，而是为了把目标信息推到最远。真实长文的信息密度更高，难度只会比这个低。
