# G8：两个截止日期并存

**测什么**：同一条通知里有两个截止时间（系统 11-07、纸质 11-10），模型选了晚的那个。

**期望**：`deadline` 如实为 11-10（因为模型给的 evidence 确实是原文里那句）。

**为什么值得测**：这条断言的是**服务端的职责边界**——它只校验「这句话在不在原文里」，**不替用户判断哪个才是真正的死线**。真正的死线（早的那个）由深度解读层指出，因为那需要理解「系统关闭后不再接受补报」这句话的因果。

把「该谁负责」分清楚，才不会写出一个既做校验又做语义裁决的四不像。

**通过判据**：服务端忠实执行证据，不做它不该做的取舍；对照 `05-interpretation` 的实际输出，解读层会明确指出 11-07 才是死线。
